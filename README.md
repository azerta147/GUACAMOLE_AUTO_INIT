# Guacamole Docker Portainer

Déploiement Apache Guacamole avec :

- Guacamole Web
- guacd
- PostgreSQL
- initialisation automatique de la base

## Déploiement Portainer

Créer une Stack depuis ce repository.

Variables :

POSTGRES_DB
POSTGRES_USER
POSTGRES_PASSWORD
GUACAMOLE_IP


Accès :

http://IP:8080/guacamole


Identifiants initiaux :

Utilisateur :
guacadmin

Mot de passe :
guacadmin


Changer immédiatement le mot de passe après connexion.
